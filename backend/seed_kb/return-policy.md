# Return Policy

We accept returns within **30 days** of delivery for unused items in original packaging.

## Eligibility

- Item must be unused and in original packaging with tags attached.
- Proof of purchase (order number + email) is required.
- Final-sale items (gift cards, underwear, personalized goods) cannot be returned.

## How to start a return

1. Contact support with your order number and email.
2. We create an RMA (return merchandise authorization).
3. Ship the item using the prepaid label within 14 days of RMA creation.
4. Refunds are issued to the original payment method within 5–7 business days after we receive the item.

## Outside the return window

Orders delivered more than 30 days ago are outside the return window. We may offer store credit only for defective items under warranty.
