# Size Guide

## Apparel (inches)

| Size | Chest | Waist | Hip |
|------|-------|-------|-----|
| XS | 32–34 | 26–28 | 34–36 |
| S | 34–36 | 28–30 | 36–38 |
| M | 38–40 | 32–34 | 40–42 |
| L | 42–44 | 36–38 | 44–46 |
| XL | 46–48 | 40–42 | 48–50 |

## Footwear

Order your usual US size. If you are between sizes, size up. Width is medium (D) unless noted.

## Fit tips

- Stretch fabrics: choose your true size.
- Structured jackets: size up if you prefer a relaxed fit.
- Exchanges for size are free within the 30-day return window.
